# AGENTS.md — Data Wiki

Контекст проекта для агентов. Правила работы и стек — в `CLAUDE.md`, план — в `PLAN.md`.

## Задача (ТЗ)

Разработать сервис организации личной базы знаний: приём документов Markdown, анализ содержимого, скоринг релевантности, полнотекстовый поиск, кэширование.

### Обязательные
1. **Обработка данных:** импорт и парсинг Markdown; анализ структуры и содержимого; валидация и нормализация.
2. **Скоринг:** расчёт релевантности; базовый метод (TF-IDF, BM25); индексация для поиска.
3. **Поиск:** полнотекстовый с релевантностью; фильтрация и сортировка; подсветка совпадений.
4. **Хранение и кэш:** тексты и метаданные; кэш запросов и результатов; версии документов.

### Дополнительные
5. Несколько методов скоринга, гибридное ранжирование, кастомные веса.
6. JWT-аутентификация, изолированное хранение, управление доступом к документам.
7. Веб-клиент: загрузка/редактирование, поиск и фильтры, статистика (число документов, размер базы).

Метаданные документов: теги, категории, авторы.

## Требования к реализации

- Языки: Go/Python/C++/C#/Java. Поиск: Elasticsearch/OpenSearch или встроенные средства (PostgreSQL FTS, Bleve). БД: PostgreSQL/MySQL/MongoDB/Redis. Кэш: Redis/Memcached. Docker + docker-compose.
- Код: чистый, с обработкой ошибок и логированием; unit-тесты ядра; интеграционные тесты API; осмысленные git-коммиты.
- Документация: README с запуском и примерами; OpenAPI/Swagger; System Design с диаграммами; техническое описание алгоритмов скоринга.
- Инфраструктура: docker-compose, миграции БД, конфиги через переменные окружения.

## Ожидаемый результат

Рабочий сервис (обязательная часть), публичный GitHub-репозиторий (код, docker-compose, README, демо-видео), документация (архитектура, скоринг, API, развёртывание и импорт данных), презентация и защита.

## Этапы

Требования → System Design → реализация → тестирование (unit, интеграция, производительность индексации, UI) → отчёт и презентация → защита.
